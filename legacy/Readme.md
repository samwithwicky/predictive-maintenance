# Legacy Development Scripts

This directory contains the original development and experimentation scripts
used while building the predictive maintenance system.

These scripts document the progression of the project from initial data
exploration through model development, evaluation, explainability,
early-warning analysis, visualization, inference, and final validation.

They are preserved for reproducibility and project history.

The current cleaned implementation is located in:

- `src/` — core machine-learning and inference logic
- `app/` — application interface
- `tests/` — automated tests
- `models/` — active model artifacts
- `reports/` — analysis and evaluation figures

The files in this directory are not required for normal application
execution.
